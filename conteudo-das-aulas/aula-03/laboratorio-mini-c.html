Laboratório Mini-C

Digite um programa e observe o caminho do texto até o significado: análise léxica, árvore sintática e atributos semânticos. O analisador roda inteiramente neste arquivo, sem internet e sem executar o código digitado.

Aguardando código

1. Código-fonte

Tipos: int, real, bool · declaração: int total = 2; · atribuição: total = total + 1; · saída: print(total);
Operadores: + - * / < > == != · booleanos: true false · comentários: // texto

2. Análise ao vivo

Roteiro de investigação

1. Remova um ponto e vírgula. Qual etapa deixa de produzir resultado?

2. Faça int idade = true;. A forma é aceita? E o significado?

3. Compare 2 + 3 * 4 com (2 + 3) * 4 na árvore.

4. Use uma variável antes de declará-la. Qual atributo permite detectar o problema?
